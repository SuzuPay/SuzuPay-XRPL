# **XRPL Accelerator and Hackathon: Best Project Examples** **XRPLアクセラレーター・ハッカソン　優秀プロジェクト事例**

This document shows examples of successful XRPL projects submitted to a hackathon to give you an idea of a good and complete submission which can help you get kickstarted. 

Do note that the rules of the hackathons were different than the one you may be building for another hackathon or accelerator program. Please refer to the rules and requirements of the hackathon or accelerator program you are competing for.

本資料では、過去に開催したハッカソンにて優秀と認められたXRPLプロジェクトの事例をご紹介します。「完成度の高い成果物」としてどのようなものが求められているのかを、貴社にて提出物をご準備される際に参考にしていただけますと幸いです。

※現在募集を受け付けているハッカソン／アクセラレータープログラムでは、ルールや評価基準が過去開催のものと異なる場合がございます。必ずご自身が参加するプログラムの最新ルールや必須条件をご確認のうえ、それに沿ってご準備いただきますようお願いいたします。

#### **Why this is a good project**

**Clear Problem**

**Strong XRPL Integration**

* **RLUSD stablecoin** enables per-second parking payments  
* **3-5 second settlement** vs. days for traditional payments  
* **Sub-cent fees** make micro-payments economically viable  
* Live transactions verified on XRPL explorer

**Working Product**

* Functional web app with NYC map (TomTom API)  
* **AI dynamic pricing** (Echo AI) based on traffic/location/time  
* Real-time billing timer with instant payment deduction  
* Complete demo: select spot → park → pay → verified on-chain

**Perfect Track Fit**

* **Payments** \+ **Stablecoin Use Cases**  
* Dual benefit: consumers save money, operators reduce fees

### **4\) PayPark (DivHacks 2025\)**

* プロジェクト概要  
* デモ動画([RLUSD)](https://www.loom.com/share/e7437d95ab6c44f09d2bd79710582aa7?sid=26e72f41-3cab-4c7b-8e05-a6d83e4119ff)  
* プロダクト全体のデモビデオ  
* [Github](https://github.com/ripple-devrel-artifacts/PayPark)

#### **評価のポイント**

**明確な課題解決**

* ニューヨークで抱える駐車場の課題を解決：15\~30分の駐車でさえ1時間分の料金を要する  
* 事業者が支払う3\~5%のカード手数料と、着金までに数日かかってしまう入金サイクルを改善

**強力なXRPLインテグレーション**

* **ステーブルコイン「RLUSD」**を活用した、1秒単位で駐車料金の支払いを完了させる  
* 従来の着金までに数日かかる決済プロセスを**「3\~5秒」に短縮**  
* マイクロ決済を経済的に実現する**安価な手数料**  
* 実際のトランザクションがXRPLエクスプローラー上で認証された

**実働可能なプロダクト**

* ニューヨークの地図(TomTom API)を搭載したWebアプリ  
* **AIを活用したダイナミックプライシング(Echo AI)**：交通量・位置情報・時間帯のデータを最適化し、需要と供給をマッチさせる  
* リアルタイムの課金タイマーと即時決済を搭載  
* 駐車場の選定→駐車→決済→オンチェーン上の認証まで、完璧なデモを披露

**テーマへの適合性**

* **決済とステーブルコインを兼ね備えたユースケース**  
* 消費者と事業者の双方にメリットを与える：消費者(ドライバー)は駐車料金を節約できる。駐車場の事業者は手数料を削減できる。
